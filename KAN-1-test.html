FAQ (Accordion)

What is HTML?
HTML (HyperText Markup Language) is the standard language used to create and structure content on the web. It uses a system of tags and attributes to define elements like headings, paragraphs, images, links, and more.
What is CSS?
CSS (Cascading Style Sheets) is a stylesheet language that describes how HTML elements should be displayed. It controls layout, colors, fonts, spacing, and responsiveness of web pages.
What is JavaScript?
JavaScript is a dynamic programming language that adds interactivity to websites. It can manipulate the DOM, handle events, communicate with servers, and power modern web applications.
What is responsive design?
Responsive design is an approach that ensures web pages render well on all devices and screen sizes. It uses flexible grids, CSS media queries, and fluid images to adapt layouts dynamically.

Code Block

<!-- A simple JavaScript greeting -->
<script>
  function greet(name) {
    const time = new Date().getHours();
    let greeting;

    if (time < 12) {
      greeting = "Good morning";
    } else if (time < 18) {
      greeting = "Good afternoon";
    } else {
      greeting = "Good evening";
    }

    return `${greeting}, ${name}!`;
  }

  console.log(greet("Piyush"));
</script>
